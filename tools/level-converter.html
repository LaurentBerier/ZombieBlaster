Level ⇄ Three.js editor converter

Round-trip data/levelData.json through https://threejs.org/editor/

1. Export levelData.json → editor scene

Builds a Three.js scene with marker objects for every entity in the level, then downloads it as level-scene.json. Open the Three.js editor and drag the file into the canvas (or use File → Import).

Click "Export" to start.

2. Import edited scene → levelData.json

Edit in the Three.js editor, then use File → Export Scene to download a .json. Drop that file here:

Choose a scene .json above to convert it back.

What the markers represent

  • Wireframe green boxes = rooms. Translate to move, scale to resize. userData.id carries the room name.
  • Solid coloured cubes = custom props. Colour is hashed from the GLB filename. userData.asset carries the GLB filename (must exist under assets/CorridorKit/).
  • Red icosahedrons = enemy spawns (only x/z survive the round-trip — the y is purely visual).
  • Cyan octahedron = player spawn.
  • Native PointLights = lights. Edit colour/intensity/distance in the editor's Light panel directly.

Anything in levelData.json with no visual representation (corridors, traps, vats, pumps, platforms — all currently empty) is stashed verbatim in scene.userData.unmappedData and re-emitted untouched on import.

To add a new prop in the editor: duplicate an existing prop cube, position it, then in the User Data panel update id (must be unique) and asset (filename of a GLB in assets/CorridorKit/).
